# Open app issues

- [ ] 008. After a delivered response exceeds the action limit, chat says “Delivery could not be confirmed”. Distinguish a received but rejected response from a genuinely interrupted delivery. Keep the duplicate-send warning for genuinely uncertain transport.
- [ ] 028. Create “Café”, then type “CAFÉ” in term completion or Dictionary search. The match disappears because SQL lower only folds ASCII. Use Unicode case folding consistently for term-name matching.
- [ ] 037. Search the Activity timeline for when an event occurred. The record stores only a sequence number and the visible rows show no time. Timestamp new events and preserve readable legacy records with unknown times.
- [ ] 038. Open Needs attention after a held job has been superseded or a question answered. The historical event remains in the actionable list solely because of its original event kind. Keep history in Timeline and filter Needs attention by current state.
- [ ] 053. Zoom a graph, switch to another project and inspect its graph. The zoom is held in one global state slot. Keep each project's scale independent.
- [ ] 054. Inspect a directory in Project graph. Its children appear as raw data and cannot be selected directly from the directory inspector. Offer a bounded list of children that opens the selected snapshot path.
- [ ] 055. Browse a deeply nested file in Project graph. Its path is text and the inspector offers no way to go up one directory. Add a parent action that stays in the same snapshot.
- [ ] 056. To change a dictionary link, the form asks for a raw dictionary ID already present on the page. Offer a named selection showing ownership and current link state.
- [ ] 057. Use the “Edit definition” form for an existing spelling. It sends neither the entry ID nor its revision and creates another entry. Clearly separate creating a definition from editing the selected entry.
- [ ] 058. Review proposed definitions in Dictionary. The decision form requires manually transferring a proposal ID from a separate list response. Let the user select a pending proposal and inspect its proposed wording before deciding.
- [ ] 059. The owner can rename a dictionary through its operation but has no Rename action in Dictionary management. Make renaming an owned dictionary available in that view.
- [ ] 060. Remove an installed skill. The user must transcribe a version ID from a raw record. Offer a named installed-version selector and preserve the backend's exact-version check.
- [ ] 061. Switch to Models overview when roles share a model but use different efforts. The selector labels show only role and model, so each row must be opened to compare. Show effective effort alongside each assignment.
- [ ] 062. Edit a model assignment during active work. The form does not explain whether the current sealed turn will change. State when the saved configuration takes effect.
- [ ] 066. Two open projects have the same folder name. Sidebar entries fall back to full paths with long identical prefixes and the differing segments are clipped. Use the shortest distinguishing path suffix while preserving each exact project identity.
- [ ] 067. Open Automation and inspect a schedule. The due instant is only a Unix integer and its period has no unit. Show UTC date/time and explain the interval, including one-time schedules.
- [ ] 068. After 32 older cancelled/dispatched schedules, an upcoming active schedule disappears from the Automation list. Prioritize active items before applying the display limit.
- [ ] 069. Schedule two different reads for the same time. The Automation records omit the action entirely, so you cannot tell which read each schedule will perform. Include the tool name without exposing connector credentials.
- [ ] 070. Produce over 100 events, then open Activity. Timeline silently discards all but the latest 100 with no way back. Provide bounded browsing to older records with a stable cursor.
- [ ] 071. With more than 80 matching terms, Dictionary silently cuts off the list. Tell the user when more matches exist and how to narrow the search.
- [ ] 072. Filter Files in Project graph, then open Relationships. The two inputs share one filter and unrelated edges disappear. Keep the two filters independent.
- [ ] 073. Page through a long relationship list. The pager has no position or result range. Show which portion of the filtered collection is on screen.
- [ ] 074. Read page two of Relationships, then enter a filter with multiple pages. The old page offset skips the first matches. Start a new filter at the first result.
- [ ] 075. Browse the file tree with both an extensionless file and a directory. Both are shown as plain paths. Identify folders in the list while preserving the underlying path used for navigation.
- [ ] 076. Capture a Rust project using `mod foo;` with `foo/mod.rs`, or a nested `mod child;` in `foo.rs`. Relationships misses these valid module locations. Resolve both conventional layouts with exact snapshot paths.
- [ ] 077. Capture a .rs or .fluxr file containing invalid UTF-8. Graph coverage counts it as indexed even though the indexer skipped it. Report only files actually examined and retain the total candidate count.
- [ ] 096. Open a binary file in Project graph after capturing it. Inspect the file description for its size and compare it with a text file. Show the retained byte length for either kind in the visible inspector.
